# 条目自适应高度

SillyTavern 插件，让各处长文本条目根据内容自动换行展开，每项可独立开关，修改即时生效。

## 安装

在 SillyTavern「扩展 → 安装扩展」中粘贴本仓库 URL 即可。

## 功能

| 开关 | 效果 |
|------|------|
| 扩展条目换行显示 | 扩展列表中过长的扩展名自动换行，不再被截断 |
| 提示词管理器条目换行显示 | 提示词列表条目名称自动换行显示 |
| 世界书 textarea 换行显示 | 世界书条目的文本框随内容自动伸缩高度 |
| 弹窗文本框换行显示 | 各类弹窗内的输入框随内容自动伸缩高度 |
| 快速回复换行显示 | 全局/当前对话/角色快速回复集的集合名称及标签均自动换行，标签输入框同步替换为可多行编辑的 textarea |
| 正则脚本名称换行显示 | 正则列表中的脚本名称自动换行，附带可调节的右侧留白 px 设置 |
| 酒馆助手脚本换行显示 | 酒馆助手脚本列表中的脚本名称自动换行 |
| 小白 x 图标替换 | 将小白X插件的折叠按钮图标替换为自定义字符（默认 ❀） |
| 正文词汇替换 | 对聊天记录正文进行关键词替换，支持多个查找词（逗号分隔），留空替换内容则为删除 |

## 说明

- 所有开关默认开启，可按需关闭
- 关闭开关后立即还原为酒馆原始显示效果
- 设置自动保存，无需手动确认
